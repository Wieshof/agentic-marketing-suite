# TOOLS — technische Fähigkeiten und Auswahl
**Keine dieser Integrationen ist durch die bloße Installation dieses Pakets aktiviert.**

| Kategorie | Beispiele | Nutzung / Voraussetzung |
|---|---|---|
| Paid Search/Google/YouTube | Google Ads API, Ads Scripts/UI | API Write-Fähigkeit je Kampagnentyp; Legacy YouTube Video meist UI/Scripts |
| Google Shopping | Merchant API + Google Ads API | Merchant Feed und Anzeigen getrennt verwalten |
| Microsoft Search & Shopping | Microsoft Advertising API | Ad-Account, Token, Rechte und jeweiliger Kampagnentyp |
| Meta | Marketing API | Business Manager, App Permissions, Review |
| LinkedIn | Marketing Developer API | OAuth, Ads Product Access, Campaign Manager |
| TikTok | Ads Manager / Business API | Konto, Region, Spark-Auth/Shop-Status |
| Amazon | Amazon Ads API | Seller/Vendor/Non-Endemic-Zulassung |
| OpenAI ChatGPT Ads | Ads Manager / Advertiser API | Freigeschaltetes Konto, Ads-Key, Creative/Product-Feed-Review |
| Retail, DSP, Audio, OOH | Vendor-API/Portal/IO | Einkaufspartner- und Rechnungsvereinbarung |
| Asset-Produktion | FFmpeg, Image-Generator, SVG, Templates | Nur beim tatsächlich angeschlossenen Capability Tool |
| Analyse | CSV/JSON, Datenabfragen, Statistik-Tools | Quelle und Attribution belegen, keine Messwerte simulieren |

Adapter dürfen ausgetauscht werden. Die kanonischen Artefakte (Briefing, Mediaplan, Creative-Brief, Launch-Manifest, Report) bleiben lesbar und exportierbar.
