# OpenAI ChatGPT Ads — Kanalprofil

**Stand:** 23.10.2026 · **Status:** Orientierungswissen, kein Live-Capability-Nachweis

## Strategische Rolle
AI-native Discovery bei kontextuell relevanten Kauf-/Entscheidungssituationen. Der Kanal ist nur geeignet, wenn Ziel, Zielgruppe, Angebot und wirtschaftliche Rahmenbedingungen dazu passen. Berate auch zur Nicht-Nutzung.

## Relevantes Anzeigeninventar
Chat cards, Shopping/Produktfeed-Kampagnen, visuelle Pilotformate, Sponsored-Agent-Pilots soweit zugelassen. Genaue Placements, zulässige Formate und Länder vor Umsetzung aktuell prüfen.

## Voraussetzungen
Ads Manager Account und Review, unterstützte Länder, Werbemittel, ggf. Feed-Access. Fehlende Voraussetzungen dürfen nicht stillschweigend als erfüllt gelten.

## Umsetzung / APIs
OpenAI Advertiser API für Campaigns, Ad Groups, Ads, Produktfeeds, Insights, auth per API key; tatsächliche Account-Rechte vor Aktion prüfen. Vor jeglicher externen Aktion: `.advertising/integrationen/ADAPTER_CONTRACT.md` und `.advertising/MEDIA_BUYING.md`; ohne Zugriff nur freigabefähigen Plan erstellen.

## Spezifisches Beratungsrisiko
Ads sind getrennt von ChatGPT-Antworten; keine Einflussnahme auf Modellantworten. Spezialformate können Beta/Pilot sein. Dokumentiere, ob Ausführbarkeit aus offizieller Dokumentation, aus tatsächlichem Kontopreflight oder nur als Option angenommen ist.
