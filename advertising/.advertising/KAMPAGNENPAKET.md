# KAMPAGNENPAKET — minimale tatsächliche Arbeitsergebnisse

Keine Vorlagenordner beim Start anlegen; erst bei einem echten Auftrag erzeugen. Für eine mehrstufige Kampagne kann der Spezialist bei Bedarf ein konsistentes Paket erstellen:

```text
advertising/kampagnen/<slug>/
├── BRIEFING.md          # Auftrag, Ziel, reale Fakten, Annahmen
├── STRATEGIE.md         # Empfehlung und Alternativen
├── LEITIDEE.md          # Creative Direction, Varianten, Proof
├── MEDIA_PLAN.csv       # Kanal, Flight, Budget, Hypothesen, Freigaben
├── CREATIVE_BRIEFS.md   # pro Format/Placement passende Assets
├── TRACKING.md          # Events, Einwilligung, Attribution, Baseline
├── LAUNCH_MANIFEST.json # zunächst DRAFT; nach Bedarf externe IDs
└── EVALUATION.md        # erst nach echten Daten; keine Fantasiewerte
```

## Minimalfall
Auf „Schreibe mir drei Google-Ads-Anzeigen“ genügen drei Varianten mit einer Empfehlung im Chat. *Nicht* für jede Kleinaufgabe das gesamte Kampagnenpaket aufbauen.

## Übergang zu Ausführung
Kampagnenpaket und Budgetfreigabe sind **noch keine Kontoberechtigung**. Erst autorisierter Kanaladapter + Preflight + Staging + gesonderte Live-Freigabe.

## Kampagne abgebrochen oder nicht sinnvoll?
Schriftliche No-Go-Empfehlung mit Gründen und alternativen Maßnahmen; keine leeren Kampagnenordner und keine Fake-IDs.
