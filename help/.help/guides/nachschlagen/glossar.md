# Glossar – Die wichtigsten Begriffe

| Begriff | Verständliche Erklärung |
|---|---|
| Agent / Spezialist | KI mit Arbeitsauftrag und Fachanweisungen; tatsächlich handelnd nur mit Werkzeugen |
| Harness | Programm, das einem KI-Modell Dateien, Werkzeuge und Arbeitsumgebung zur Verfügung stellt |
| `AGENT.md` | Einstiegstext, der die Rolle und das Verhalten eines Fachbereichs festlegt |
| Methode | Anleitung, wie der Spezialist ein Fachproblem lösen sollte |
| Artefakt | Erstelltes Arbeitsergebnis wie Konzept, Bild oder CSV |
| Briefing | Ausgangsinformationen über Ziel und Rahmenbedingungen |
| USP | behaupteter oder belegter unterscheidender Angebotsvorteil |
| SWOT | Analyse von Stärken, Schwächen, Chancen und Risiken |
| KPI | Messgröße zur Beobachtung eines Ziels |
| Conversion | Gewünschte Handlung, etwa Kontaktanfrage oder Kauf |
| Preflight | Vorprüfung auf bestimmte Fehler und fehlende Voraussetzungen |
| Freigabe | Autorisierte Zustimmung zu einem konkreten Ergebnis oder einer Aktion |
| Provenienz | Herkunftsnachweis einer Information oder Datei |
| Context Pack | Kleiner, zweckbezogener Ausschnitt relevanten Wissens |
| noCMS | KI-gestütztes Website-Verfahren ohne traditionelles CMS |
| noCRM | Individuelle KI-gestützte Beziehungskommunikation statt Massenansprache |
| Dashboard | Optionale Browseransicht; keine zusätzliche Agenten-Engine |
| API | Technische Schnittstelle zwischen Programmen |
| JSON / CSV / Markdown | Lesbare Daten- und Dokumentformate |
