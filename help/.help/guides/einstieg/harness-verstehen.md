# Was ist ein KI-Harness?

Das **KI-Modell** erzeugt Antworten. Der **Harness** stellt Arbeitsumgebung und Werkzeuge bereit, etwa Dateien lesen, bearbeiten, Programme ausführen und gegebenenfalls Dienste kontaktieren. Beispiele sind Pi, Codex und Claude Code.

Die Suite enthält Methoden und Arbeitsanweisungen, keinen eigenen vollständigen Harness. Für reine Beratung genügt ein Modell mit Zugriff auf die relevanten Texte. Zum dauerhaften Bearbeiten von Dateien wird ein schreibender Zugriff benötigt. Eine wirkliche E-Mail erfordert zusätzliche funktionierende Mailwerkzeuge.

**Einstieg:** Geben Sie dem Harness den Pfad zum Workspace und lassen Sie die passende `AGENT.md` lesen.
