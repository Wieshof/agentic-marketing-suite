# Keine Marketingkenntnisse nötig

Sie müssen nicht wissen, was SWOT, USP oder Funnel bedeutet. Beschreiben Sie Ihr Problem in Ihren eigenen Worten. Der Spezialist entscheidet, ob eine Methode dafür nützlich ist und erklärt bei Bedarf, warum er sie verwendet.

**Beispiel:** „Unsere Website wird kaum besucht. Finde heraus, ob wir eine neue Website brauchen oder zuerst etwas anderes verbessern sollten.“

Achten Sie auf das Ergebnis: Haben Sie eine nachvollziehbare Empfehlung, konkrete nächste Schritte und klar gekennzeichnete Annahmen erhalten? Wenn nicht, bitten Sie um Überarbeitung – nicht um ein weiteres langes Interview.
