# Welchen Fachbereich soll ich auswählen?

| Anliegen | Geeigneter Fachbereich |
|---|---|
| Bekanntheit, Ziele, Marketingkonzept | `marketing/` |
| Pressemitteilung, journalistische Kontakte | `pr/` |
| Posts, Reels, Shorts und Community | `social-media/` |
| Website planen und mit noCMS bauen | `website/` |
| Werbekampagne, Anzeigen und Mediaplan | `advertising/` |
| Gestaltung, Videos, Print, Audio | `creative/` |
| Persönliche Kommunikation, Kontakte | `noCRM/` |
| Kampagnenwirkung, Dateninterpretation | `analytics/` |
| Online-Shop, Produktfeed, Conversion | `e-commerce/` (falls vorhanden) |
| Unternehmenswissen strukturieren | `business-dna/` (optional) |
| Markenidentität und Markenführung | `branding/` (optional) |

Die Liste beschreibt mögliche Fachbereiche und entspricht nicht automatisch der tatsächlich installierten Auswahl. Im Zweifel die vorhandenen Ordner prüfen. Ein größerer Auftrag kann mehrere Spezialisten brauchen; der Help-Spezialist erstellt dafür nur einen verständlichen Startauftrag.
