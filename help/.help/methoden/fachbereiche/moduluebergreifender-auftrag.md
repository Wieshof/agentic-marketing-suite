# Wie arbeiten mehrere Fachbereiche zusammen?

**Fachmethode:** `moduluebergreifender-auftrag` · **Bereich:** fachbereiche · **Zuständigkeit:** suite

## Zweck
Eine konkrete Hilfe liefern zur Frage: **Wie arbeiten mehrere Fachbereiche zusammen?**.

## Wann einsetzen
Bei einer Kampagne mit mehreren Leistungen.

## Vorgehen
1. Beschreibe die fachliche Notwendigkeit mehrerer Module.
2. Erkläre den Root-Einstieg und optionales Suite-Wissen.
3. Unterscheide mögliche Koordination im vorhandenen Harness vom simplen Dateizugriff.

## Ergebnis
Kompakter Gesamtauftrag als Vorlage.

## Qualitätskontrolle
Help ist kein eigener Orchestrator oder Workflow-Engine.

## Zusammenarbeit
Falls zur Umsetzung ein Fachspezialist erforderlich ist, dessen Existenz im aktuellen Dateibaum prüfen und einen fertigen Auftrag formulieren. Diese Methode selbst führt keine externe Aktion aus.
