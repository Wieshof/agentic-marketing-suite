# Nur zur technischen Demonstration – keine realen TOPACA-Werte

Die Datei `topaca-demo-synthetisch.csv` enthält absichtlich **frei erfundene, synthetische** Wochenwerte. Sie dient ausschließlich dem Test der CSV-Auswertung und darf **niemals** für einen realen Marketingbericht oder zur Wirkungsbeurteilung verwendet werden. Die Zeitreihen zeigen keine kausale Wirkung. Das Beispiel ist nur dazu da, den technischen Workflow und die Warnhinweise vorzuführen.
